## 문제

[괄호 회전하기](https://school.programmers.co.kr/learn/courses/30/lessons/76502)

**1. 문제 분석**
- 대괄호 `[]`, 중괄호 `{}`, 소괄호 `()`로 이루어진 문자열 `s`가 주어짐
- `s`를 왼쪽으로 `x`칸(0 <= x < s의 길이) 회전시켰을 때 올바른 괄호 문자열이 되는 `x`의 개수 반환

**2. 제약조건**
- `s`의 길이는 1 이상 1,000 이하
- 문자열 길이가 최대 1,000이므로 O(n^2) 풀이 가능
- 시간 복잡도: O(n^2)
- 공간 복잡도: O(n)

**3. 단계별 구현절차**
- 문자열의 길이가 홀수인 경우 올바른 괄호 쌍을 이룰 수 없으므로 바로 0 반환
- 0부터 `s.length() - 1`까지 시작 위치를 이동(회전)하며 유효한 괄호 문자열인지 판별:
  - 여는 괄호(`(`, `[`, `{`)일 경우 스택에 push
  - 닫는 괄호(`)`, `]`, `}`)일 경우:
    - 스택이 비어있으면 올바르지 않은 괄호이므로 false
    - 스택 top을 꺼내서 짝이 맞지 않는 경우 false
  - 모든 문자를 확인한 후 스택이 완전히 비어있어야 true
- 유효한 경우 count 증가 후 최종 count 반환

```java
import java.util.*;

class Solution {
    public int solution(String s) {
        if (s.length() % 2 != 0) return 0;

        int count = 0;
        int n = s.length();

        for (int i = 0; i < n; i++) {
            if (isValid(s, i, n)) {
                count++;
            }
        }

        return count;
    }

    private boolean isValid(String s, int start, int n) {
        Deque<Character> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            char ch = s.charAt((start + i) % n);

            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);
            } else {
                if (stack.isEmpty()) return false;

                char top = stack.pop();
                if (ch == ')' && top != '(') return false;
                if (ch == ']' && top != '[') return false;
                if (ch == '}' && top != '{') return false;
            }
        }

        return stack.isEmpty();
    }
}
```
