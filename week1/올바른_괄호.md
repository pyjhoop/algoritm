## 문제
[올바른 괄호](https://school.programmers.co.kr/learn/courses/30/lessons/12909)

**1. 문제 분석**
- 문자열 s가 주어지고 s 는 '(', ')'로 구성되어있다.
- 괄호가 올바르게 짝지어졌는지 판단

**2. 제약조건**
- s의 길이는 100,000 이하의 자연수
- 시간 복잡도 O(n)
- 공간 복잡도 O(1)

**3. 단계별 구현절차**
- s의 길이만큼 순회하여 현재 index의 문자가 어떤 괄호인지 확인
- '('면 sum++, ')'면 sum--; 
- ++ 또는 -- 후에 음수면 false;
- s길이만큼 순회후 sum이 0이면 true 아니면 false


```java
class Solution {
    boolean solution(String s) {
        
        int sum = 0;
        
        for(int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            
            if(ch == '(') sum++;
            else sum--;
            
            if(sum < 0) return false;
        }
        
        return sum == 0;
    }
}

```
