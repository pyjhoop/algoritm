## 문제 

**1. 문제 분석 및 목표**
- 총 N 마리중 N/2 마리 선택 
- 선택할 수 있는 종류의 최대 개수 구하기

**2. 제약조건 및 복잡도**
- nums 길이: 최대 10,000
- 원소 값: 1 ~ 200,000
- 시간복잡도: O(n)
- 공간복잡도: O(n)

**3. 단계별 구현절차**
- HashSet을 선언해 nums의 모든 요소를 add(중복제거)
- set.size()와 nums.length / 2 중 작은 것 반환 (Math.min)



## 구현 코드
```java
import java.util.*;

class Solution {
    public int solution(int[] nums) {
        Set<Integer> set = new HashSet<>();
        
        for(int num : nums) {
            set.add(num);
        }
        
        return Math.min(set.size(), nums.length / 2);
    }
}
```
