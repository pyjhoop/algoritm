## 문제 
[1. Two Sum](https://leetcode.com/problems/two-sum/description/)

## 문제분석
정수형 배열과 정수 target이 주어짐
배열의 값중 두개를 합쳐서 target 값이 나오는 인덱스 구해야함
값은 반드시 하나만 나오게 설정되어있음

## 제약조건
- 2 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- 시간복잡도 : O(N^2)까지 가능
- 공간복잡도 : O(N)

## 풀이방법
1. 배열의 길이의 최대가 10^4이기에 이중 반복문으로 풀어도됨
2. HashMap을 사용해 요소값을 key, 인덱스를 value로 둬서 값을 구함

```java
import java.util.*;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();

        // map 세팅
        for(int i = 0; i < nums.length; i++) {
            map.put(nums[i], i);
        }        

        for(int i = 0; i < nums.length; i++) {
            int rest = target - nums[i];
            // rest가 map에 있는지 확인
            int index = map.getOrDefault(rest, -1);

            if(index == -1 || index == i) continue;

            return new int[]{index, i};
        }
        return new int[]{0,0};
    }
}
```

어떤 값을 찾을 때 반복문으로 찾아야할걸 O(1) 으로 바꾸고 싶을때 Hash를 사용하면 된다.
