## 문제
[242. Valid Anagram](https://leetcode.com/problems/valid-anagram/description/)

## 문제 분석
- t, s 문자열 두개가 주어짐
- s가 t의 길이와 같으면서 t가 s의 모든 단어의 개수를 포함하면 true 아니면 false

## 제약조건
- 1 <= s.length, t.length <= 5 * 104
- s and t consist of lowercase English letters.
- 시간 복잡도 : O(N) ~ O(NlogN) 까지 가능 
- 공간 복잡도 : O(N)

## 풀이 방법
1. 소문자 a ~ z 까지니 크기 26인 배열에 s에 포함된 문자 개수 추가 해서 풀기
2. HashMap 이용해서 문제 풀기


```java
import java.util.*;

class Solution {
    public boolean isAnagram(String s, String t) {

        Map<Character, Integer> map = new HashMap<>();

        // s에 있는 모든 문자 추출해서 문자 개수 저장하기
        for(int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            int value = map.getOrDefault(ch, 0);
            map.put(ch, ++value);
        }

        // t에 있는 문자 추출해서 map에 있는지 확인후 없으면 false 아니면 1차감 및 remove
        for(int i = 0; i < t.length(); i++) {
            char ch = t.charAt(i);
            int value = map.getOrDefault(ch, 0);

            if(value == 0) return false;
            
            if(value > 1) {
                map.put(ch, --value);
            }else {
                map.remove(ch);
            }
        }

        if(map.isEmpty()) return true;
        
        return false;
    }
}
```
