## 문제 
[contains-duplicate](https://leetcode.com/problems/contains-duplicate/)

## 문제 분석
nums 정수형 배열에 하나라도 동일한  값이 있으면 true 모든 값이 하나씩만 있으면 false 리턴한다.

## 제약조건
- 1 <= nums.length <= 105
- -109 <= nums[i] <= 109
- 시간 복잡도 O(n);
- 공간 복잡도 O(n);
- num이 10^9 까지니깐 정수자료형

## 풀이방법
1. 배열을 Arrays.sort(nums)로 정렬 후 현재값과 다음값을 비교해 동일하면 true 리턴 아니면 false 리턴
2. HashMap으로 진행

```java
import java.util.*;

class Solution {
    public boolean containsDuplicate(int[] nums) {

        Map<Integer, Integer> map = new HashMap<>();

        for(int num : nums) {
            // get으로 하면 null 처리해야함
            // containsKey 로 boolean 리턴으로 할 수도 있음.
            int value = map.getOrDefault(num, 0);
            if(value > 0) return true;
            map.put(num, 1);
        }
        return false;
    }
}
```
