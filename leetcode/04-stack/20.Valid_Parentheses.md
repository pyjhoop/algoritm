## 문제 
[20. Valid Parentheses](https://leetcode.com/problems/valid-parentheses/description/)

## 문제분석
문자열 s 가 주어지고 '(', ')', '{', '}', '[', ']' 로 이루어짐 
s의 괄호 짝이 올바른 경우 true 아니면 false

## 제약조건
1 <= s.length <= 104
s consists of parentheses only '()[]{}'.

## 풀이방법
stack을 이용해서 열리는 괄호 인경우는 add 하고 닫히는 괄호일때 이전 괄호 확인해서 짝을 이루는경우 pop 아닌 경우 false 리턴 
마지막에 stack이 비어있는지 여부 리턴

```java
import java.util.*;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            // 1. 여는 괄호는 스택에 추가
            if (c == '(' || c == '{' || c == '[') {
                stack.push(c);
            } 
            // 2. 닫는 괄호 처리
            else {
                // 스택이 비어있으면 닫는 괄호와 짝을 이룰 여는 괄호가 없음
                if (stack.isEmpty()) {
                    return false;
                }

                char openBracket = stack.pop();
                // 짝이 맞지 않으면 즉시 false
                if (!isPair(openBracket, c)) {
                    return false;
                }
            }
        }

        // 모든 문자를 처리한 뒤 스택에 여는 괄호가 남아있지 않아야 유효
        return stack.isEmpty();
    }

    private boolean isPair(char open, char close) {
        return (open == '(' && close == ')') ||
               (open == '{' && close == '}') ||
               (open == '[' && close == ']');
    }
}
```
