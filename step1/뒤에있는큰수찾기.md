## 문제
[뒤에 있는 큰 수 찾기](https://school.programmers.co.kr/learn/courses/30/lessons/154539)

**1. 문제 분석**
- numbers 배열이 주어짐
- 배열 내의 각 요소별로 뒷 큰수를 찾아야함
- 뒷 큰수는 자신보다 뒤에있는 숫자중 자신보다 크고 가장 가까운수를 말한다.

**2. 제약조건**
- numbers의 길이는 최대 10^6 이기에 O(n^2) 불가능 최선은 
- 시간 복잡도 O(n)
- 공간 복잡도 O(n)

**3. 단계별 구현절차**
- numbers와 동일한 크기의 answer 배열 생성 및 모든 요소를 -1로 초기화
- 아직 뒷 큰수를 찾지 못한 원소들의 인덱스를 저장할 stack 생성
- numbers 배열을 인덱스 0부터 numbers.length - 1까지 순회:
- stack이 비어있지 않고, stack의 최상단 인덱스가 가리키는 값(numbers[stack.peek()])이 현재 값(numbers[i])보다 작은 동안 반복:
- stack에서 인덱스를 꺼내(pop) prev에 저장
- answer[prev]를 현재 값(numbers[i])으로 갱신
- 조건 검사가 끝나면 현재 인덱스 i를 stack에 push
- 순회 종료 후 answer 배열 반환 (스택에 남아있는 인덱스는 뒷 큰수가 없으므로 초기값 -1 유지)

```java
import java.util.*;
class Solution {
    public int[] solution(int[] numbers) {
        int[] answer = new int[numbers.length];
        
        Deque<Integer> stack = new ArrayDeque<>();
        
        // 응답 배열 기본값을 -1로 세팅
        for(int i = 0; i < answer.length; i++) {
            answer[i] = -1;
        }
        
        // numbers 순회하면서 스택에 값이 있고 나보다 작은 값이면 answer의 해당 인덱스의 값으로 number 값 추가후에 pop 해야함.
        for(int i = 0; i < numbers.length; i++) {
            while(!stack.isEmpty() && (numbers[stack.peek()] < numbers[i])) {
                int prev = stack.pop();
                answer[prev] = numbers[i];
            }
            stack.push(i);
        }
        
        return answer;
    }
}
```
