## 문제

[카드 뭉치](https://school.programmers.co.kr/learn/courses/30/lessons/159994)

**1. 문제 분석**
- 카드배열 2개와 목표 배열 1개가 주어진다.
- card1, card2 배열에서 순서대로 문자열을 추출해서 goals 배열을 만들 수 있으면 Yes 못하면 No 반환

**2. 제약조건**
- arr 크기 1 이상 10 이하
- 시간 복잡도 O(n)

```java
class Solution {
    public String solution(String[] cards1, String[] cards2, String[] goal) {
        int index1 = 0;
        int index2 = 0;
        
        for(String keyword: goal) {
            if(cards1.length > index1 && cards1[index1].equals(keyword)) {
                index1++;
                continue;
            }
            if(cards2.length > index2 && cards2[index2].equals(keyword)) {
                index2++;
                continue;
            }
            
            return "No";
        }
        return "Yes";
    }
}
```
