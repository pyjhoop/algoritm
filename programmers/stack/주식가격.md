# 문제
[주식가격](https://school.programmers.co.kr/learn/courses/30/lessons/42584)

---

## 1. 문제 분석
- 초 단위로 기록된 주식가격이 담긴 배열 `prices`가 주어짐.
- 각 시점의 가격이 **몇 초 동안 가격이 떨어지지 않았는지**를 계산하여 정수 배열 형태로 반환.
- **핵심 포인트**: 가격이 바로 다음 초에 떨어지더라도, 떨어지기 전까지 1초의 시간은 흐른 것으로 간주함.

---

## 2. 제약조건
- `prices`의 각 가격은 1 이상 10,000 이하인 자연수.
- `prices`의 길이는 2 이상 100,000 이하.
- $N$이 최대 100,000이므로 단순 이중 루프 최악의 경우 $O(N^2)$ (약 $10^{10}$)으로 시간 초과 위험이 존재함. 스택을 활용한 $O(N)$ 풀이가 정석.
- **시간 복잡도**: $O(N)$
- **공간 복잡도**: $O(N)$

---

## 3. 단계별 구현절차
1. 결과를 담을 배열 `answer`와 시점(인덱스)을 보관할 `stack` 생성.
2. 0초부터 마지막 시점까지 인덱스 `i`를 순회:
   - 스택이 비어있지 않고, **스택의 top 시점 가격 > 현재 시점 가격(`prices[i]`)**인 경우:
     - 가격이 떨어진 것이므로 스택에서 인덱스(`prevIndex`)를 꺼냄.
     - 버틴 시간 계산: `answer[prevIndex] = i - prevIndex`
     - 현재 가격보다 높은 이전 시점들이 스택에 남아있지 않을 때까지 반복.
   - 현재 인덱스 `i`를 스택에 push.
3. 순회가 끝난 후 스택에 남아있는 인덱스 처리:
   - 끝까지 가격이 떨어지지 않은 시점들.
   - 스택에서 인덱스를 꺼내며 버틴 시간 계산: `answer[prevIndex] = (n - 1) - prevIndex`
4. 최종 `answer` 배열 반환.

---

## 4. 코드 구현

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] solution(int[] prices) {
        int n = prices.length;
        int[] answer = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // 현재 가격이 이전 가격보다 떨어졌다면 스택에서 꺼내며 기간 계산
            while (!stack.isEmpty() && prices[stack.peek()] > prices[i]) {
                int prevIndex = stack.pop();
                answer[prevIndex] = i - prevIndex;
            }
            stack.push(i);
        }

        // 끝까지 가격이 떨어지지 않고 스택에 남아있는 인덱스 정산
        while (!stack.isEmpty()) {
            int prevIndex = stack.pop();
            answer[prevIndex] = (n - 1) - prevIndex;
        }

        return answer;
    }
}
```
